# Test vectors

Every file here is generated by [`../conformance/build-vectors.ts`](../conformance/build-vectors.ts) from fixed keys and times. Don't edit them by hand.

## Format

`<kind>/<valid|invalid>/<name>.json`:

```json
{
  "description": "What this vector checks.",
  "context": { "keylog": [ … ] },
  "input": …,
  "expect": { "valid": true, "cid": "sha256:…" }
}
```

An invalid vector expects `{ "valid": false, "reason": "<reason>" }`. An implementation **must** agree on `valid`, and **should** report the same `reason`; Scape's own suite requires both.

| Kind | `input` | `context` | Derived values a valid vector checks |
|---|---|---|---|
| `keylog` | The entries, genesis first | — | `account`, `headHash` |
| `record` | A record | `keylog` | `cid` |
| `log` | `{ entries, checkpoint }` | `keylog`, `after` (`{ seq, head }` or `null`) | — |
| `checkpoint` | A checkpoint | `keylog` | — |
| `proof` | A sign-in proof | `keylog`, `audience`, `nonce`, `now` | — |
| `file` | `{ bytes, ref }`, `bytes` in base64url | — | — |
| `scape` | A manifest | — | `serve`: for each `request`, the `path` served (or `null`) and the `status` |

`context.keylog` is always valid; verify it first.

## Reasons

When an object breaks several rules, report the first that fails, in this order:

1. **Shape:** `bad_shape` (wrong type, pattern or count), `bad_version` (`v` is not 0).
2. **Identity and ordering:** `bad_seq`, `bad_account`, `bad_prev`, `deactivated`.
3. **Encoding and size:** `not_integer` (a fractional or unsafe number anywhere, found while canonicalizing), `too_large`.
4. **The key:** `unknown_key`, `revoked_key`, `unknown_restriction`, `key_restricted`.
5. **The signature:** `bad_signature`.
6. **Content:** `schema`, `bad_path`, `bad_entry`, `bad_head`.
7. **Proof context** (checked after shape, before the key): `bad_audience`, `bad_nonce`, `window_too_long`, `expired`.
8. **Files:** `bad_size`, then `bad_hash`.

The reference library in [`../src`](../src) is the precise statement of this order.
